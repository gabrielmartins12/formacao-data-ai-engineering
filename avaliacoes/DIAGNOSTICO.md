# Diagnóstico inicial (60–90 minutos)

Objetivo: definir o ponto de partida sem apagar o progresso anterior. Não é prova eliminatória.

## Parte A — lógica/Python (25 pontos)
Sem IA gerando código: escreva um programa que receba uma lista de transações fictícias com categoria e valor, ignore valores inválidos e imprima total por categoria. Explique a decomposição, execute e mostre um caso de erro.

## Parte B — Linux/Bash (25 pontos)
Em diretório de teste, encontre arquivos .csv, conte linhas contendo ERRO com grep e escreva script que retorna código diferente de zero se o CSV não existir. Explique find vs grep, redirecionamento e código de saída.

## Parte C — Git (25 pontos)
Explique e demonstre git status, add, commit, log e diff em um repositório de laboratório. Descreva como reverter uma mudança não commitada sem perder trabalho alheio.

## Parte D — SQL (25 pontos)
Escreva em papel/arquivo uma consulta que some valores por categoria em tabela transacoes(id,categoria,valor). Explique WHERE, GROUP BY e o que acontece com NULL.

## Rubrica
- Raciocínio e explicação: 25
- Implementação/consulta: 35
- Teste e depuração: 25
- Segurança, Git e clareza: 15

Registrar competências já demonstradas; ajustar a dificuldade da Semana 1. Não assumir domínio com base apenas na resposta teórica.
